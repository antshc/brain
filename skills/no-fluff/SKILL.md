## Formatting Instructions

When formatting or updating a text:

1. Preserve all existing meaning and decisions.
2. Prioritize directness and facts: keep only sentences that add actionable value; cut any that just take up space.
3. no-fluff: no bloat, filler words, redundant explanations, verbose phrasing. If the text already has no removable bloat, leave it unchanged.
4. Do not add new content unless the user provides it.

Apply the rewrite in place: edit the target file, or if the text was given inline, return the full rewritten text. Provide no commentary or summary of changes.
