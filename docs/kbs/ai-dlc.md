## AI DLC
| Term | What it is | Main idea |
|---|---|---|
| **AI-DLC** | An **AI-native development methodology** | Redesign the development lifecycle around AI agents |
| **AI-SDLC / Agentic SDLC** | A **broader operating model/framework** for putting AI across the SDLC | Humans + agents collaborate throughout requirements → production |
| **Automating SDLC with AI agents** | An **automation approach** | Keep your existing SDLC, but automate individual steps with agents |

## Flow
```
Issue created
   ↓
Orchestrator
   ├─► codebase research agent
   ├─► requirements agent
   └─► dependency research agent
          ↓
      design agent
          ↓
      coding agents
       ├─ slice A
       ├─ slice B
       └─ slice C
          ↓
      review agents
          ↓
       CI / tests
          ↓
      PR → human approval
```

## Level 1
```

AI-assisted development

Human works
AI helps

"Write this test."
"Explain this code."
```

## Level 2
```

SDLC automation with agents

Human process stays mostly the same
Agents perform steps

Ticket
 → Research Agent
 → Coding Agent
 → Review Agent
 → PR
```

## Level 3
```

AI-native SDLC / AI-DLC

The lifecycle itself is redesigned
around agent execution.

Intent
 → structured research
 → decisions
 → specifications
 → functional slices
 → autonomous implementation
 → automated verification
 → human governance
```
