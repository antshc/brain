# Draft document

Create or update specifications, high-level designs and Transfer of Information (TOI) documents.

| Route | Result |
|---|---|
| `spec` | Specification |
| `hld` | High-level design |
| `toi` | TOI document |

Use `draft` for new content, `update` for existing content, or `normalize` to revise only behavioral requirements. Untyped requirements fragments use `draft-document normalize`, applying the spec requirements rules.

Examples: `draft-document spec`, `draft-document hld update`, `draft-document toi`.

[SKILL.md](SKILL.md) selects the route and directly discloses its resources. Playbooks own procedures; templates own output structure; local references own requirements and HLD update rules.

Callers retain discovery, decisions, decomposition, evidence dispatch, approvals, worktrees, integration and publication. This skill returns authored content, source conflicts and unresolved gaps.
