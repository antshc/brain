# Code Diagram

## Class Diagram

Show class responsibilities, fields, methods, inheritance, interfaces, dependencies, composition, aggregation, and class-level changes. Use Mermaid `classDiagram`.

In delta mode include changed classes, members, and relationships plus the minimum context.

Put `%% diagram-id: {{diagramId}}` after the `%%{init: …}%%` theme directive and immediately above `classDiagram`.

Official Mermaid class diagram syntax: https://mermaid.ai/open-source/syntax/classDiagram.html
