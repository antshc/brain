# Record Term

Capture **one resolved term** into `CONTEXT.md` in the same turn it crystallises — never batch. Load [CONTEXT-FORMAT.md](../templates/CONTEXT-FORMAT.md) for structure and rules. The file's existence is guaranteed by `bootstrap-docs`; this procedure only writes into it.

## Keep it in its lane

`CONTEXT.md` is a **glossary only** — totally devoid of implementation details. Not a spec, not a scratch pad, not a repository for implementation decisions.
