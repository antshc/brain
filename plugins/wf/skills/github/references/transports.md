# Transports

Use the GitHub integration for ChatGPT publication when it supports the complete operation and its read-back. Use `GH_TOOL` with authenticated `gh` in CLI environments. Implement Spec requires `GH_TOOL` for graph, checkpoints and publication contracts. The CLI never calls the integration. For generic Git branches, commits and worktrees, load `git` and use `GIT_TOOL`. If a required capability is absent, stop dependent work and report known state.
