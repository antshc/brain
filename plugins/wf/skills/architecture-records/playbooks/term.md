# Record term

## Inputs

One resolved term, its context/definition, and the established GLOSSARY.md path.

## Prerequisites

Missing glossary → report the prerequisite; return control to the router for **Select and load**, route `initialize`, only when requested.

## Record term

Capture one resolved term in the existing GLOSSARY.md in the same turn it crystallises; never batch. Apply the glossary format's context, terminology, and definition rules. Keep implementation detail and implementation decisions out of the glossary.

## Completion criteria

The resolved term appears in its context; unrelated content is preserved.
