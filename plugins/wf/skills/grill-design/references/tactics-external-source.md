# External-Source Cross-Reference

Trigger: the session is seeded from an explicit external link/reference, such as a Jira item, Confluence page, or GitHub issue.

Persist the source URL/identifier and relevant claims/evidence in the frontier; track it for the session. Missing access or source content → report a fact gap, not an inferred source requirement.

When a statement, decision, or resolved term contradicts it, cite the source and conflicting answer immediately and ask which applies. Once resolved, offer the exact source correction that turn.

An external-source edit is the only exception to the parent's local writable-surface list. Require user confirmation of the exact target and wording before writing. A missing write-capable tool leaves the source stale; report it. A failed authorized write follows the parent's bounded-retry protocol and stays pending in the ledger.

Confirm the update result before marking it synchronized. Persist the resolved wording, source status, and any pending correction so the next turn or handoff can continue without repeating approval.
