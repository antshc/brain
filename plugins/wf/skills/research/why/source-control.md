# Source control

Why investigator source, including the anchor. Apply the Investigator brief.

*Load and follow the `git` skill to trace file and line history* using History: rename-following, text search, blame back to the introducing change, co-changed files, and commits naming work items. Read the PRs found through the `github` skill. Also check in-repo context: inline comments and TODOs near the target, ADRs, related tests (names and assertions encode motivating edge cases), CHANGELOG and release notes.

Defensive target (null check, retry, timeout, rate limit, feature flag, egress guard, OOM handler) → look for "fix for incident", "add defensive check", or a revert followed by "re-apply with…".
