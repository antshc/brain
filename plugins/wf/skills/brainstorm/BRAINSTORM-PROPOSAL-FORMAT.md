# Brainstorm Proposal Format

Use this format to present the single recommended option before approval.

```md
## Proposed Approach: {{approachName}}

{{One-sentence summary}}

- **Strengths:** {{key advantages}}
- **Weaknesses:** {{key disadvantages}}
- **Best when:** {{conditions where this approach fits}}

### Reasoning

{{Explain why this approach fits or does not fit the agreed goals, constraints, risks, and expected usage. State which trade-offs are acceptable and which could make the approach unsuitable.}}
```
