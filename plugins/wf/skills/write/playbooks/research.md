# Write a research report

Use supplied questions, findings, methods, environments, confidence, evidence, gaps and proposed next steps. Drafting adds no research, measurements or decisions. The caller owns saving and publication.

1. Match each subject to its supplied finding, supporting evidence and status. Return missing evidence as an explicit gap. For updates, read the supplied document and preserve unaffected content, protected source text and decisions. Done when all supplied subjects and conflicts are accounted for.
2. Execute the directly disclosed Bottom line procedure with the supplied findings. Reuse its returned bullets; do not recursively invoke this skill. Done when each subject has a finding, consequence and action or explicit status.
3. Fill the Research template and apply Report language. Preserve route-specific explanations, diagrams, technical evidence, source coverage and confidence as additional sections. Cite material claims in place and link every evidence report in References. Resolve source links from the caller's destination; if absent, keep canonical URLs or report the unresolved local-link base. Done when evidence remains independently traceable and incomplete claims retain their status.
4. Return the complete body plus update summary, conflicts and gaps separately. Remaining work includes each unproven claim and what would confirm it, or explicitly states no remaining work. Next steps remain distinct from unfinished investigation. Done when no placeholder remains and the report implies no unperformed check or unsupported completion.
